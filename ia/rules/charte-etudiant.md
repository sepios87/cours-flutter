# Charte d'utilisation de l'IA

L'IA est autorisée pour apprendre, comprendre une erreur, explorer des solutions et relire un travail. Elle ne remplace pas le raisonnement, le code ni la capacité à expliquer le rendu.

En utilisant l'IA, l'étudiant s'engage à :

- partir de sa propre compréhension du besoin avant de demander du code ;
- écrire et tester les étapes proposées ;
- signaler l'aide importante reçue dans son journal IA ;
- être capable d'expliquer les widgets, le flux de données et les choix de son projet ;
- ne pas rendre une solution générée qu'il ne sait pas modifier ou justifier.

Une aide IA n'est pas pénalisée lorsqu'elle est comprise, adaptée et déclarée. En revanche, pendant une démonstration ou une question orale, l'étudiant doit pouvoir justifier son code. L'enseignant peut demander une modification simple en direct pour vérifier cette compréhension.

## Réflexe de qualité

Avant d'intégrer une suggestion, l'étudiant doit pouvoir répondre à ces quatre questions :

1. Quel problème ce code résout-il ?
2. Pourquoi ce widget ou cette approche est-elle adaptée ?
3. Que se passe-t-il si l'utilisateur interagit avec l'écran ?
4. Comment puis-je vérifier que cela fonctionne ?
