# Préparer ma demande à l'IA

Copie et complète ce modèle avant de demander de l'aide pour une feature.

```text
Contexte du TP :
Feature à ajouter :
Ce que l'utilisateur doit pouvoir faire :
Ce qui existe déjà dans mon projet :
Ma première idée (widgets / données / interaction) :
Ce que j'ai déjà essayé :
Ce qui me bloque exactement :
Niveau d'aide souhaité (question, indice, squelette, exemple local) :
```

Ne cherche pas à remplir parfaitement toutes les lignes. Une première hypothèse, même fausse, donne à l'IA une base pour t'aider à raisonner.
